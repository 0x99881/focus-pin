# 专注钉

[English README](README.md)

专注钉是一款本地优先的电脑专注工具，主要面向容易分心、执行困难，或有 ADHD 类注意力困扰的人。它不是把任务越堆越多，而是帮你从一团想法里，看清现在最值得做的一件事，并立刻开始一个足够小的动作。

它的核心顺序很简单：先随手记下，再判断主线，今天最多选三件，一次只专注一个小步骤。

## 它想解决什么问题

普通待办工具很擅长保存内容，但常常没有解决这些真正让人卡住的问题：

- 突然想到的事情应该放在哪里？
- 现在真正的主线是什么？
- 一件模糊的大事，怎样变成马上能开始的小动作？
- 怎样让倒计时不只是一个数字，而是能感受到时间正在经过？
- 长期想法、今天要做的事和专注过程，怎样自然连在一起？

专注钉把自由纸面、主线图、今日检查、专注倒计时和超小悬浮窗放在同一个客户端里，让这些决定变得更直接。

## 推荐使用顺序

1. 有想法时，先放进“快速收集”，或者在纸面上双击添加文字。
2. 在纸面上随便写、画、涂、标记和移动内容，不要求一开始就整理好。
3. 把需要推进的事情放到“主线图”，分成主线、支线或以后再做。
4. 从中选出今天最多三件事。
5. 只指定一个当前任务，并把它拆成不超过三个专注步骤。
6. 选择常用时长或自定义倒计时，时间到后会播放简短的内置提示音。
7. 完成后写一句结果，以后可以回看；误删的内容也可以恢复。

## 五个主要区域

### 今日检查

这是每天打开后最先看的地方，也是整个产品的中心。今天最多保留三件事，避免所有任务同时争夺注意力。其中只有一件是当前任务，另外两件只是等待，不会一直催促你。

你可以：

- 随手记下一件事，暂时不要求归类；
- 把事项放到今天或明天；
- 指定当前任务；
- 完成、修改、调整顺序或移除事项；
- 从选中的任务直接开始专注。

### 专注时间

专注页让时间更有存在感。你可以选择常用时长，也可以输入自己的倒计时；然后只看当前任务和最多三个小步骤。倒计时支持暂停、继续、重新开始和提前完成。时间到后使用简短的内置提示音，不依赖外部音乐文件。

### 超小悬浮窗

当你不想让完整界面占据屏幕时，可以切换到超小悬浮窗。它只保留当前动作和倒计时，其他操作在鼠标移上去时才出现。只有这个小窗会保持在其他窗口上方；普通最小化仍然和一般软件一样进入任务栏，不会一直挡住桌面。

### 纸面

纸面是用来放松思考的地方。打开后不用先选画笔，直接就能写写画画；双击空白位置就能添加文字。你还可以使用荧光笔、橡皮擦、撤销，切换纸张底纹，移动便签，并把便签直接放入今天或明天。

纸面支持格子、点阵、横线和空白四种样式。

### 主线图

主线图不要求你先学会一套复杂的排序方法，而是把注意力分成三层：

- 主线：现在最值得投入精力、最不能被替代的事情。
- 支线：对主线有帮助，但不应该抢走主要注意力的事情。
- 以后：值得保留，但今天不需要处理的事情。

事项可以手动拖动。原有的档位选择仍然保留，方便快速调整；颜色和视觉重量会一起表现轻重缓急，让主次不只藏在一个数字里。

### 全部数据

这里用于整理和回看，不需要每天一直盯着。未完成事项、明天的事项、提醒、完成记录和回收站都集中在这里。你可以修改备注、调整顺序、恢复误删内容，也可以导出一份整理好的表格。

## 中英文切换

专注钉提供完整的简体中文和英文界面。

- 全新安装会跟随电脑语言：中文系统默认显示中文，其他系统默认显示英文。
- 可以随时点击标题栏里的 `EN / 中文` 切换。
- 页面名称、按钮、弹窗、日期、状态提示和导出表格都会跟随所选语言。
- 你自己写的任务、便签和纸面内容不会被翻译或改写。

## 隐私与数据安全

专注钉不需要账号、API 或云服务，也不包含统计与行为追踪。

- 个人任务和笔记只保存在当前电脑。
- 公开项目中不包含个人任务历史、提醒内容、恢复文件或定制化示例。
- 全新安装从通用的空白内容开始。
- 每次修改都会自动保存。
- 本地会保留上一版，并定时留下多份恢复副本。
- 如果主要数据文件损坏，启动时会尝试从有效的本地副本恢复。
- 删除内容会先进入回收站，可以恢复。

Windows 下的实际使用数据保存在：

```text
%APPDATA%\desktop-focus-memo
```

这个文件夹属于本机使用数据，不会进入项目仓库。

## 在本机运行

需要：

- Windows 10 或 Windows 11
- Node.js 20 或更新版本
- npm

```powershell
git clone <你的项目地址>
cd pin
npm install
npm start
```

依赖安装完成后，也可以在 Windows 上双击 `启动专注钉.cmd`。

## 检查项目

```powershell
npm test
$env:FOCUS_MEMO_SMOKE='1'; npm start
```

检查内容包括任务与纸面数据、本地备份和恢复、表格导出、中英文切换、窗口行为，以及主要使用流程。

## 当前状态

专注钉目前是一个面向个人使用的本地电脑端雏形，暂时没有账号、多人协作、云同步、手机端或截图发送功能。这些功能不是遗漏；当前最重要的目标，是先把一个不依赖网络、安静、稳定、真正能帮助人开始行动的电脑工具做好。
